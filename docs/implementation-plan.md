# 当前实现范围

- GitHub 公开安装与正式 Release 更新，默认不静默替换源码。
- Python 3.9+ 与系统 curl；本机单页、随机端口、会话验证、Key 内存存储。
- 自然语言输入与一次可选方向追问；复杂语义由宿主先整理。
- 后台固定筛选口径、50 次请求与 US$0.50 本地预留限制。用户点击生成才授权该轮查询。
- 匿名读取 TikHub 官方报价，校验接口身份与 USD/次契约；不让用户手填单价。
- curl 配置通过 stdin 传递，密钥不进命令参数或文件；不跟随跳转、不启用 curlrc。
- 固定计算与事实模板，保留相关性判断来源，区分关键词命中和语义审核。
- 安装更新保护本地修改，备份在用户数据目录，支持跨磁盘目标。
- 远程验收配置已完成；当前 GitHub 登录缺少 workflow 权限，待授权上传执行。
- 手册缩为两页；当前试用稿采用本机合成数据截图，远程验收后更换正式证据。
