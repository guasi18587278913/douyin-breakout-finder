# 0.2 产品升级范围

- GitHub 公开分发；安装器记录来源版本，升级保留用户运行数据，默认只检查更新，不暗中替换代码。
- Python 3.9+ 本地网页向导，监听 127.0.0.1 随机端口；密钥只在向导内存中保留，页面不回显、日志不落盘，不要求 GitHub token。
- 两到三轮需求澄清：当前内容/主题与目标 → 受众、内容角度、排除项 → 关键词与预算确认。
- 公共价格元数据自动取得；未取得有效报价时不能启动付费研究。保留明确的人工报价回退，不能假定单价。
- 固定事实报告模板与结构化宿主输出校验；弱模型不负责计算、费用或结论字段。自动相关性规则提供可解释的初筛，用户/宿主可复核边界候选。
- 核心流程继续 TikHub 直连。可选宿主模型仅用于语言理解和深度摘要；不得将 AgentKey 误称为分析模型。
- GitHub Actions 独立 Linux 环境：从公开 GitHub 下载并安装，多目录兼容检查，真实浏览器驱动向导与合成数据闭环，截图与报告制品。
- Windows 的无网络单元/安装测试；实际客户端或实际模型未运行的矩阵必须注明。
- 使用 2—3 页 PDF 替换复杂手册，优先讲复制链接安装、申请 TikHub key、填表、回答问题、看报告。

测试边界：公开 CI 不包含真实密钥或私人研究数据。模拟数据测试不等于已验证真实 TikHub 付费查询。当前尚未得到把真实密钥传到 GitHub secrets 的授权，也未获得新增付费模型/API试跑的明确上限。
