# v0.2.0 公测

新增本地网页向导：自然语言输入、一次方向追问、Key 弹窗和自动报告。运行结束清除会话 Key，支持中途停止后续查询并保留已有结果。

新增公开 GitHub 安装/更新入口：正式 Release 分发、本地修改检测、旧版本备份和独立数据目录。

新增固定事实模板与相关性来源标注，明确关键词初筛、播放对照核验、语义待复核各自的含义。

新增远程独立环境验收配置（待授权执行）：Ubuntu/Windows 核心检查、公开下载安装和真实浏览器截图。远程测试不含真实 Key、真实客户端会话或真实付费 API 查询。

本版供体验与反馈；各宿主客户端的实际体验仍需持续验证。

补回宿主智能体持续研究：收费前握手、逐条语义复核与有界补搜、正文证据登记、完整研究报告。没有助手、缺正文或统计未完成时，明确区分阶段报告。修复了离线续写后页面不更新、证据并发登记丢失等问题。
